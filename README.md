# Crypto Market App

A Windows 11 desktop application for tracking cryptocurrency market data from CoinMarketCap's Upbit page.

## Features
- Real-time tracking of top 10 cryptocurrencies by trading volume
- Interactive data visualization with zoomable charts
- Automatic data refresh every 5 minutes
- Historical data tracking and visualization

## Installation
Please follow the instructions in `build_windows.md` to build the application for Windows 11.

## Requirements
- Python 3.12.x
- See `requirements.txt` for full list of dependencies

## Usage
1. Launch the application by double-clicking the executable
2. View real-time cryptocurrency data in the main table
3. Click on any cryptocurrency to view its historical trend chart
4. Data automatically refreshes every 5 minutes

## Support
If you encounter any issues, please follow the troubleshooting steps in `build_windows.md`.
