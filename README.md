# Cryptocurrency Market Bot\nA Telegram bot that provides real-time cryptocurrency market updates from CoinMarketCap's Upbit exchange.\n\n## Features\n- Real-time cryptocurrency market data from Upbit exchange\n- Top 10 cryptocurrencies by trading volume\n- Automatic updates every 5 minutes\n- Easy-to-use Telegram commands\n- Robust error handling and retry mechanism\n\n## Prerequisites\n- Ubuntu Linux server (18.04 LTS or newer)\n- Python 3.12 or newer\n- pip (Python package installer)\n- Telegram Bot Token (obtain from @BotFather)\n\n## Installation\n\n1. Update system packages:\n```bash\nsudo apt update\nsudo apt upgrade -y\n```\n\n2. Install Python and required system packages:\n```bash\nsudo apt install -y python3-pip python3-venv\n```\n\n3. Clone the repository:\n```bash\ngit clone https://github.com/vaynewilltom/my-first-repo.git\ncd my-first-repo\n```\n\n4. Create and activate a virtual environment:\n```bash\npython3 -m venv venv\nsource venv/bin/activate\n```\n\n5. Install dependencies:\n```bash\npip install -r requirements.txt\n```\n\n## Configuration\n\n1. Create a `.env` file in the project root:\n```bash\ncp .env.example .env  # If .env.example exists\n# OR\ntouch .env           # If creating from scratch\n```\n\n2. Add your Telegram Bot Token to the `.env` file:\n```\nTELEGRAM_BOT_TOKEN=your_bot_token_here\nLOG_LEVEL=INFO\n```\n\nReplace `your_bot_token_here` with the token obtained from @BotFather.\n\n## Deployment\n\n### Using systemd (Recommended)\n\n1. Create a systemd service file:\n```bash\nsudo nano /etc/systemd/system/crypto-market-bot.service\n```\n\n2. Add the following configuration:\n```ini\n[Unit]\nDescription=Crypto Market Bot\nAfter=network.target\n\n[Service]\nType=simple\nUser=your_username\nWorkingDirectory=/path/to/my-first-repo\nEnvironment=PYTHONPATH=/path/to/my-first-repo\nExecStart=/path/to/my-first-repo/venv/bin/python src/main.py\nRestart=always\nRestartSec=10\n\n[Install]\nWantedBy=multi-user.target\n```\n\nReplace `your_username` and `/path/to/my-first-repo` with your actual values.\n\n3. Enable and start the service:\n```bash\nsudo systemctl daemon-reload\nsudo systemctl enable crypto-market-bot\nsudo systemctl start crypto-market-bot\n```\n\n4. Check service status:\n```bash\nsudo systemctl status crypto-market-bot\n```\n\n### Manual Deployment (Development)\n\nFor testing or development, run directly:\n```bash\npython src/main.py\n```\n\n## Bot Commands\n\n- `/start` - Start receiving cryptocurrency market updates\n- `/stop` - Stop receiving updates\n- `/status` - Check bot status and number of active subscribers\n\n## Monitoring\n\n### View Logs\n\nApplication logs:\n```bash\n# If running directly\ntail -f crypto_bot.log\n\n# If running as systemd service\nsudo journalctl -u crypto-market-bot -f\n```\n\n### Check Bot Status\n```bash\n# View service status\nsudo systemctl status crypto-market-bot\n\n# View recent logs\nsudo journalctl -u crypto-market-bot -n 50\n```\n\n## Troubleshooting\n\n1. Bot not responding:\n   - Check if the bot is running: `sudo systemctl status crypto-market-bot`\n   - Verify the bot token in `.env` file\n   - Check logs for errors: `sudo journalctl -u crypto-market-bot -n 100`\n\n2. No data updates:\n   - Check internet connectivity\n   - Verify the scraping URL is accessible\n   - Check logs for scraping errors\n   - Ensure the service is running: `sudo systemctl status crypto-market-bot`\n\n3. Permission issues:\n   - Ensure proper file permissions: `chmod 644 .env`\n   - Verify service user has required permissions\n   - Check log file permissions\n\n## Security Considerations\n\n1. Secure the `.env` file:\n```bash\nchmod 600 .env\n```\n\n2. Create a dedicated service user:\n```bash\nsudo useradd -r -s /bin/false crypto-bot\nsudo chown -R crypto-bot:crypto-bot /path/to/my-first-repo\n```\n\n3. Update systemd service to use dedicated user:\n```ini\n[Service]\nUser=crypto-bot\nGroup=crypto-bot\n```\n\n4. Restart service with new user:\n```bash\nsudo systemctl daemon-reload\nsudo systemctl restart crypto-market-bot\n```\n\n## Maintenance\n\n1. Update the application:\n```bash\ngit pull origin main\nsource venv/bin/activate\npip install -r requirements.txt\nsudo systemctl restart crypto-market-bot\n```\n\n2. Rotate logs (if needed):\n```bash\nsudo truncate -s 0 crypto_bot.log\n```\n\n3. Monitor disk usage:\n```bash\ndu -h crypto_bot.log\n```\n\n## Support\n\nFor issues and feature requests, please create an issue in the GitHub repository.
