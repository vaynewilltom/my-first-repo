Crypto Market App for Windows 11
===========================

Quick Start
----------
1. Extract the downloaded zip file to any location
2. Double-click "crypto_market_app.exe" to start the application
3. The application will open automatically and begin displaying cryptocurrency data

What to Expect
-------------
- Real-time cryptocurrency market data will load automatically
- The window displays the top 10 cryptocurrencies by trading volume
- Data refreshes automatically every 5 minutes
- Click any cryptocurrency to view detailed charts

Troubleshooting
--------------
1. If the application doesn't start:
   - Make sure you've extracted all files from the zip
   - Try running as administrator
   - Check your antivirus isn't blocking the application

2. If no data appears:
   - Check your internet connection
   - Wait a few seconds for initial data load
   - Close and restart the application

3. For any other issues:
   - Ensure you have a stable internet connection
   - Make sure Windows 11 is up to date
   - Contact support if problems continue

Features
--------
- View real-time cryptocurrency market data
- See top 10 cryptocurrencies by trading volume
- Click on any cryptocurrency to view historical trends
- Automatic data refresh every 5 minutes
- Interactive charts with zoom functionality
